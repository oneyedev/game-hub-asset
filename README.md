# Game Hub Asset — 디자이너 작업 가이드

이 저장소는 게임 코드 저장소 [games-hub](https://github.com/oneyedev/games-hub)에서 런타임에 비교할 **공개 이미지 후보**를 관리한다. 게임별 규격은 각 게임 폴더의 README가 기준이다.

## 시작하기
1. 작업할 게임의 README를 읽는다. 현재: [Flowforge](flowforge/README.md).
2. 게임이 요구하는 원본 리소스 경로, 레이어, 프레임 구성과 기준점을 확인한다. 모르면 추측하지 않고 게임 코드 담당자에게 매핑을 요청한다.
3. 같은 디자인 세트에 속한 모든 이미지는 동일한 색감·선·재질·광원·원근 기준으로 제작한다.
4. 해당 세트의 동일한 상대 경로에 **유효한 PNG**를 업로드하고 `flowforge/sets.json`에 세트 항목을 등록한 뒤 게임의 Art Studio에서 비교한다.
5. 이미지 수정 후 Reload(F6 지원)를 사용한다. 실제 게임 화면의 위치·가림·애니메이션을 확인한다.

## 권장 폴더 구조
```text
<game-id>/
  README.md
  sets/
    <set-id>/
      towers/<tower-id>/<asset-name>.png
      monsters/<monster-id>/<asset-name>.png
      environment/<asset-name>.png
```
위는 **제작용 경로 규칙**이다. 폴더만 만들면 게임에 자동 등록되는 것은 아니다. Flowforge는 `flowforge/sets.json`에 세트를 등록하면 게임 재배포 없이 Art Studio 선택지에 나타난다. 게임 코드의 원본 `res://` 경로 ↔ 상대 경로 매핑에 등록된 이미지에 한해 런타임 교체된다. 다른 게임은 각자 별도 규칙을 둘 수 있다.

## 디자인 세트와 세부 후보
- **세트 비교:** A/B/C는 개별 이미지가 아니라 통일된 아트 디렉션 전체를 의미한다. 세트 사이에는 동일한 상대 경로를 사용한다.
- **세부 후보:** 기준 세트를 상속하고 변경할 이미지 파일만 별도로 오버라이드한다. 다른 타워를 복제하지 않는다.
- **Original:** 게임 빌드에 포함된 원본. 후보 파일이 없거나 다운로드/디코딩에 실패하면 원본을 유지한다.
- **중요:** 새 세트는 `flowforge/sets.json`에 등록해야 나타난다. 후보 이미지가 업로드되어도 게임 코드에 원본 리소스 매핑이 없는 파일은 자동으로 교체되지 않는다.

## 파일 납품 기준
- 파일명과 디렉터리명은 소문자 영문·숫자·하이픈·언더스코어를 사용한다. 경로 대소문자를 바꾸지 않는다.
- 투명도가 필요한 스프라이트는 알파 채널을 보존한 PNG로 출력한다. 배경색을 이미지에 굽지 않는다.
- 교체 대상의 **캔버스 크기·프레임 수·프레임 배치·중심점·여백**을 원본과 동일하게 유지한다. 임의 크롭, 좌우 반전, 레이어 합치기는 금지한다.
- PNG 확장자만 맞춘 가짜 파일은 불가하다. 정상 디코딩을 확인한다. 손상 시 화면에는 내장 원본이 남을 수 있다.
- 공개 저장소다. 비밀키, 유료/비공개 소스, 권리 불명 원본을 업로드하지 않는다. 출처·라이선스를 보존한다.

## 확인 절차
- 업로드한 파일이 GitHub에서 열리고 Raw URL로 직접 접근 가능한지 확인한다.
- 게임의 Art Studio에서 해당 세트를 선택하고 Reload한다. 다운로드 성공과 **실제 적용 여부**를 구분한다.
- 정상 화면, 타워/몬스터 겹침, 방향 전환, 애니메이션, 다른 해상도에서 잘림을 확인한다.
- 파일을 올렸는데 안 보이면 **매핑 미등록 → 파일 경로/대소문자 → HTTP/CORS → PNG 디코딩 → 렌더링 경로** 순으로 확인한다.
- GitHub Raw를 Godot HTTPRequest로 읽으며 CORS를 우회하지 않는다. 이미지별 JSON 매니페스트나 프록시는 사용하지 않는다. 세트 목록 `flowforge/sets.json`만 Godot HTTPRequest로 읽는다. 실패 시 내장 세트 목록을 사용한다.

## 저장소 운영
- 확정된 디자인 세트를 기준으로 신규 에셋을 추가한다. 탐색 중인 스타일은 별도 세트로 분리한다.
- 기존 후보 파일을 덮어쓸 때는 게임에서 Reload하여 새 바이트가 반영되는지 확인한다.
- 폐기된 과거 `asset_manifest` JSON 및 `asset_hub=archer-01` 전용 모드는 현행 Flowforge의 진입 경로가 아니다.
- 게임별 실제 파일 명세·예제는 해당 게임 README를 우선한다.
