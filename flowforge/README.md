# Flowforge — 게임 에셋 제작 가이드

## 채택된 기본 세트

[Village](sets/village/README.md)의 아처 성장형 10종 38 PNG와 마법사 8형태 24 PNG, 총 62개는 게임 빌드에 포함된다. 게임 시작 시 원격 다운로드 없이 같은 모습을 표시한다. 원격 후보 `village`는 내장본과 최신 수정본을 비교하기 위해 남긴다. Forest/Stone과 구형 전용 매니페스트·시험 PNG는 제거했다.

## 타워 공격 연출 — 정식 제작 계약

타워 제작은 발사점·투사체/광선·명중 효과를 포함한다. [투사체 디자인 규격 v1](PROJECTILES.md)의 공통 캔버스·기준점·14종 역할 매핑·Art Studio 검수 절차를 따른다. `projectiles-v1`의 14종·28 PNG는 아처·마법사 노스킬 판의 승인된 메인 번들이다. Art Studio는 이후 원격 수정본 비교에 사용한다.

## 공성 기본 번들

[공성 제작 규격](SIEGE_ART.md)의 승인 콘셉트 10종은 공성 노스킬의 기본 번들이다. 타워 50 PNG와 투사체 4종·8 PNG를 제공한다. 공성 노스킬 판에서 스튜디오 선택 없이 바로 표시한다. `siege-v1`은 원격 수정본 비교에 사용한다. 초라한 기본 발판·현대식 중병기/발리스타·지붕 위 대포를 올린 천막과 작업자 2명 구조를 따른다.

## 공병 스튜디오 후보

[공병 제작 규격](ENGINEER_ART.md)에 따라 `engineer-v1`에서 승인 라인업 10종을 비교한다. 기본 공병·노움은 1명, 코볼트는 2명이며 특화는 함정 제작대·크레인·원형 굴착 시설·공사 천막으로 구분한다. 타워 44장과 투사체 3종·6장, 총 50 PNG다. 공병 노스킬 → Art Studio → **engineer-v1**에서 선택하며 기본 번들 채택은 별도다.

## 현재 교체 규격

| 분류 | 현재 규격 |
| --- | --- |
| 건물 후면/전면 | 256×256 RGBA |
| 기본 아처 I/II 인물 | 384×192, 96px 셀, 정면/왼쪽/오른쪽/후면 |
| 엘프 I 인물 | 384×192, 96px 셀, 정면/오른쪽/후면/왼쪽 |
| 나머지 7종 인물/무기 | 1024×512, 256px 셀, 정면/오른쪽/후면/왼쪽 |

행은 대기/공격 또는 작업이다. 정령·룬·저격은 1인이고 개틀링은 장전수·사수·회전포를 분리한다. 투명 여백과 프레임 내부 위치를 임의로 자르지 않는다. 타워 묶음은 0.70 배율이며 아처 II의 바닥선 보정과 단계별 실제 그림 폭을 유지한다. 전투 쿨타임·피해·교대 발사는 에셋 수와 별개다.

## 원격 후보

마법사 노스킬 `mage-01`의 [8형태](sets/village/towers/mage/README.md)는 `towers/mage/`에 있다. 후면/전면은 256×256, 인물은 1024×512(256px 셀), 열 정면/오른쪽/후면/왼쪽, 행 대기/시전이며 형태마다 1명이다. 카탈로그는 아처 38개와 마법사 24개를 포함한다. 마법사도 `mage-01`의 기본 번들에 포함되며 Art Studio 없이 표시한다.

경로는 `flowforge/sets/<id>/towers/archer/<tower-folder>/<file>.png`다. [sets.json](sets.json)의 `root`, `files`, 필요한 `overrides`를 갱신한다. 게임 매핑 키는 `res://game/art/sets/village/` 아래의 실제 내장 리소스 경로다. 새 타워 종류·파일 종류를 추가하면 게임 코드 연결도 필요하다. 몬스터·환경 등 다른 범주는 별도 매핑을 확인한다.

Art Studio를 열어 **village → Reload/F6**로 원격 수정본을 비교하고 **Built-in Village**로 내장본에 복귀한다. Studio가 닫혀 있으면 시작 시 원격 요청을 하지 않는다. 네트워크·디코딩 실패 시 내장 PNG를 유지한다.

같은 세트는 색감·외곽선·재질·광원·원근을 통일한다. 후면 → 인물/무기 → 전면의 가림과 네 방향을 실제 게임에서 확인한다. PNG 디코딩, 캔버스·셀·프레임, 알파, 바닥 기준점과 잘림을 검수한다.

## 내장본 갱신

원격 수정이 채택되면 정확한 에셋 커밋의 PNG를 `game/art/sets/village/`에 동기화하고 `source.json`의 SHA-256을 갱신한다. 게임 리소스 참조와 렌더링 배율을 확인한 뒤 `archer-01`·`mage-01` 선택 검증과 실제 PCK 내 62개 리소스 로딩 검증을 통과시켜 배포한다. 폴더 복사만으로 기본 세트가 전환되지는 않는다.
