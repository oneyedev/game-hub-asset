# Village 아처 3종 시안

Art Studio에서 **새로고침 → Village 아처 3종 시안**을 선택한다. 아처 성장형 기본 공격 판에서 타워를, **투사체 테스트**에서 비행·명중 프레임을 비교한다. 카탈로그는 타워 PNG 11장과 투사체 PNG 6장을 제공한다.

| 타워 | 구성 | 방향별 미리보기 |
| --- | --- | --- |
| 저격수 | 석조 초소, 대기 중 닫힌 덧문, 공격 시 저격수 등장 | [대기·공격](towers/archer/sniper_one_unit/preview.png) |
| 개틀링 | 쌍굴뚝 포좌, 사수·장전수·회전포 분리 | [대기·공격](towers/archer/gatling_two_unit/preview.png) |
| 룬궁수 | 호박색 비석과 하단 룬, 엘프 궁수 한 명 | [대기·공격](towers/archer/rune_one_unit/preview.png) |

미리보기 열은 정면·오른쪽·후면·왼쪽, 행은 대기·공격이다. 저격수 대기 인물 셀은 은폐 상태를 표현하기 위해 투명하다. 건물 시안에 기존 Village의 독립 방향별 포즈를 재배치하고 색을 보정했다. 비행·명중 PNG는 기존 4프레임 원화의 재색상 후보이며 발사점과 발사 주기는 현재 게임을 따른다. 본체 치수는 저격수 232×195px, 개틀링 231×180px, 룬궁수 221×233px이며 256px 셀의 바닥을 y=244에 등록했다.
