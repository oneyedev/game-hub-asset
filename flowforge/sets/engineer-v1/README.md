# Engineer v1 — Approved default

[공병 아트 규격](../../ENGINEER_ART.md)을 따른다. 공병 노스킬에서 스튜디오·네트워크 없이 바로 표시되는 승인된 기본 번들이다. `engineer-v1`은 최신 원격 수정본 비교용이다.

- 10종 타워: 기본 공병·노움 6종은 각 1명/4레이어, 코볼트 4종은 각 2명/5레이어. 총 44 PNG·주민 14명.
- 건물/전면 256², 공구 1024×512(4방향×대기/작동), 작업자별 1024×256(4방향).
- 투사체 3종·6 PNG: 물리 공구탄, 작업석, 실제 3타 강화 표시. [원본 SVG 생성 도구](../../tools/build_engineer_projectiles.py).
- 특화는 낮은 함정 제작대·높은 크레인·원형 굴착 시설·공사 현장 천막으로 구분한다. 노스킬에서는 고정 소품으로 표시하며 유료 스킬은 발동하지 않는다.
- 기본 공병·노움의 보조 인물, 깃발·인장·문장·로고를 추가하지 않는다. 상세 인원·기준점·원화 출처는 각 `meta.json`을 따른다.
