# Village — 아처 성장 라인업 10종

레벨 1의 따뜻한 목재·깔끔한 외곽선·작은 화면 가독성을 기준으로 아처 성장형 10종을 같은 화풍으로 제작했다. 전투 수치·공격 간격·인원수·공격자 교대 규칙은 기존 게임을 따른다.

| 형태 | 폴더 (`towers/archer/` 이하) | 게임 PNG 수 |
| --- | --- | --- |
| Lv.1 Archer I | `base_i_two_unit` | 4 |
| Lv.2 Archer II | `base_ii_two_unit` | 4 |
| Lv.3 Elf I | `elf_two_unit` | 4 |
| Lv.4 Elf II | `elf_ii_two_unit` | 4 |
| Lv.5 Spirit | `spirit_one_unit` | 3 |
| Lv.5 Rune | `rune_one_unit` | 3 |
| Lv.3 Dwarf I | `dwarf_i_two_unit` | 4 |
| Lv.4 Dwarf II | `dwarf_ii_two_unit` | 4 |
| Lv.5 Gatling | `gatling_two_unit` | 5 |
| Lv.5 Sniper | `sniper_one_unit` | 3 |

게임용 PNG는 총 **38개**다. 건물 후면/전면 20장, 인물 및 개틀링 무기의 4방향×2포즈 아틀라스 18장(144프레임)이다. 각 폴더의 `meta.json`이 해당 형식·방향 순서·기준점·레이어 순서를 설명한다.

- 기본 아처 I/II와 엘프 I: 256×256 건물, 384×192 캐릭터 시트, 96×96 셀. **인간 I/II의 열은 정면/왼쪽/오른쪽/후면, 엘프 I의 열은 정면/오른쪽/후면/왼쪽**이다. 같은 셀 크기여도 방향 순서는 다르다.
- 엘프 II·정령·룬·드워프 I/II·개틀링·저격수: 256×256 건물, 1024×512 인물/무기 시트, 256×256 셀. 열은 정면/오른쪽/후면/왼쪽이다. 셀 안의 그림 위치 자체가 건물과 정렬되어 있으므로 임의 크롭하지 않는다.
- 모든 시트의 첫 행은 대기, 둘째 행은 공격 또는 작업 포즈다. 각 방향은 별도 원화이며 좌우 반전으로 대체하지 않았다.
- 정령·룬·저격수는 1명, 일반 2인 타워는 2명이다. 개틀링은 사수·장전수·회전포 3개 시트를 사용한다. 원격 원본 경로 `gatling_actor_0`은 장전수, `gatling_actor_1`은 사수, `gatling_actor_2`는 회전포다.
- 후면은 캐릭터 없이 숨겨진 부분까지 완성된 그림이다. 전면은 같은 그림의 실제 난간 윤곽을 따라 추출해 픽셀과 투명 가장자리가 일치한다. 개틀링의 장전수는 앞쪽 왼편에 서며 전면 벽이 가리지 않게 분리했다.
- X/Y 동일 배율로 정렬하고 알파를 유지한다. 각 인물의 발 기준점은 방향·포즈 사이에 유지한다. 새 개틀링 무기의 총구 섬광은 해당 공격 프레임 안에 포함한다.

## 적용

`flowforge/sets.json`의 Village 항목은 게임용 PNG 38개를 `files`에 명시한다. 게임의 `game/dev_asset_proxy.gd`는 원본 경로를 이 세트의 PNG 상대 경로로 매핑한다. PNG를 수정하면 게임 재배포 없이 Reload/F6로 다시 읽을 수 있다. 새 파일 종류를 추가할 때는 게임 매핑도 필요하다.

새 게임 빌드에서 **Art Studio → village → Reload**, **`village: 38/38 textures`**를 확인한다. Original은 모든 레이어를 내장 원본으로 복구한다. 부분 세트인 Forest/Stone은 후면 1개만 명시하며 나머지는 원본을 유지한다. `files`를 생략한 이전 카탈로그도 지원한다.

`lineup.png`와 각 폴더의 `assembled.png`, `preview.png`, `preview.webp`는 납품 PNG로 조립한 미리보기다. 실제 플레이 캡처가 아니다. 게임은 실제 타워 상태에 맞춰 방향·공격/작업 프레임을 선택한다.

## 제작·검수

사용자가 제공한 성장 라인업과 게임에 있는 계열별 콘셉트를 디자인 기준으로 삼고, 프로젝트의 레벨 1 Village 에셋 화풍을 참조해 이미지 생성 도구로 새 원화를 제작했다. 배경·잔여 픽셀 제거, 전면 윤곽 추출, 균일 축소, 프레임 정렬과 합성 검수를 수행했다. 유료 외부 에셋 파일을 포함하지 않는다.

Godot 4.6.3에서 38개 PNG의 실제 로딩·원본과의 캔버스 호환, 실제 게임 씬의 텍스처 교체·Original 복귀·부분 폴백과 Village를 선택한 `archer-01`의 10형태 검증을 통과했다. PNG 전체의 RGBA/알파·디코딩, 144프레임의 비어 있음·중복·셀 경계 잘림 검사도 통과했다. 브라우저에서의 수동 플레이 확인과 자동 검증은 별개다.
