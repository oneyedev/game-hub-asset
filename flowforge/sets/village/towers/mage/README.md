# Village 마법사 — 노스킬 기본 번들

사용자의 마법사 성장 라인업을 바탕으로 `mage-01` 노스킬 관찰의 **현재 8형태**를 제작했다. 참고 이미지의 소서리스 II·흑마법 II는 별도 게임 프로필이 없으므로 추가하지 않았다. 스킬·수치·성장 규칙은 바꾸지 않는다.

| 프로필 | 폴더 |
| --- | --- |
| 마법사 I / II | `base_i` / `base_ii` |
| 소서리스 / 화염 / 비전 | `sorceress` / `fire` / `arcane` |
| 흑마법 / 저주 / 부패 | `dark` / `curse` / `decay` |

각 폴더는 후면/전면 256×256 RGBA PNG와 `mage.png` 1024×512, 총 게임용 **24 PNG**를 제공한다. 인물은 타워마다 1명이다. 256×256 셀의 열은 정면/오른쪽/후면/왼쪽, 행은 대기/시전이다. 8종에 총 64프레임이며 각 방향은 별도 원화다. `meta.json`에 발 기준점을 기록했다. 프레임 내부 여백을 잘라내거나 좌우 반전하지 않는다.

후면에는 인물이 없고 옥상 바닥까지 완성되어 있다. 전면은 후면의 실제 픽셀을 난간 상단을 따르는 다각형 마스크로 추출했다. 후면→인물→전면 순서로 같은 256px 좌표에 합성한다. `assembled.png`와 `lineup.png`는 납품 PNG로 조립한 디자인 미리보기이며 게임 캡처가 아니다.

**게임에서:** 마법사 노스킬 관찰(`mage-01`)을 열면 8형태를 즉시 표시한다. PNG 24개는 게임 빌드에 포함되어 원격 다운로드를 기다리지 않는다. 아처 38개를 합쳐 내장본·카탈로그 모두 총 62개다. 다른 마법사 스킬 관찰에는 적용하지 않는다.

Art Studio의 `village`는 이 저장소의 최신 수정본과 비교하는 선택적 기능이다. Reload/F6로 갱신하며 Built-in Village·Studio 비활성·네트워크 실패·부분/규격 불일치 패키지는 내장 PNG를 표시한다. 원격 수정은 배포된 기본값을 자동 갱신하지 않는다.

매핑 키는 실제 내장 경로 `res://game/art/sets/village/towers/mage/…`다. 게임 `source.json`이 채택한 에셋 커밋과 PNG별 SHA-256을 고정한다. 새 기본값을 채택할 때는 내장 PNG·해시·선택 시나리오·내보낸 PCK의 62개 리소스 검증을 함께 갱신한다.

원화는 사용자 참고 이미지의 건축·색상 구분과 Village의 따뜻한 외곽선·화풍을 기준으로 OpenAI 이미지 생성 도구로 새로 제작했다. 에셋 시트 추출·프레임 정렬·PNG 합성 검수는 별도로 수행했다. 외부 유료 에셋을 포함하지 않는다.
