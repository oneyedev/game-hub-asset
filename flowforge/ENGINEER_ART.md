# 공병 타워 아트 규격 v1

승인된 공병 라인업 10종을 Art Studio 후보 `engineer-v1`으로 제공한다. 게임의 **공병 노스킬 → Art Studio → engineer-v1**에서 선택한다. 기본 번들 채택은 별도다. 타워 44 PNG와 투사체 6 PNG, 총 50 PNG다. 0.70 타워 배율을 아처·마법사·공성과 동일하게 사용한다.

## 인원과 건물 실루엣

| 디자인 | 인원 | 건물과 고정 소품 |
| --- | --- | --- |
| 공병 I·II | 인간 각 1명 | 초라한 목재 작업대·뒤쪽 공구 차양, II는 철제 보강 |
| 노움 I·II | 노움 각 1명 | 청록 지붕 정밀 작업장·기어·릴, II는 강화된 동일 계열 |
| 함정반 | 노움 1명 | 낮고 넓은 열린 제작대, 왕복 레일에 정박한 톱·접힌 용수철 발판 |
| 공작반 | 노움 1명 | 높은 개방형 A자 크레인 작업장, 집게·윈치·주차된 소형 개틀링 시제품 |
| 코볼트 I·II | 코볼트 각 2명 | 적갈색 지붕 광산 작업장·석재 입구·토사 장비 |
| 굴착반 | 코볼트 2명 | 원형 철재/석재 땅굴 시설·상부 드릴·토사 도르래·작은 두더지 |
| 인력반 | 코볼트 2명 | 카키색 **공사 현장 천막이 본체**, 나무 기둥·밧줄·접힌 입구·작업대·공구·헬멧 |

전체 주민은 14명이다. 기본 공병과 노움에 보조 인물을 추가하지 않는다. 코볼트는 주황색 작업반장과 황갈색 조수로 구분하며 긴 귀·짧은 주둥이·꼬리를 유지한다. 두더지는 작은 동물 소품이며 추가 작업자가 아니다. 특화는 부모 건물의 작은 소품 교환이 아니라 건물의 높이·지붕·외곽선부터 구분한다. 인력반은 기와집·서커스 천막·군용 진지가 아니다. 깃발·인장·문장·별 무늬·로고를 넣지 않는다.

## 분리 레이어

`sets/engineer-v1/towers/engineer/<form>/`에 아래 PNG를 둔다. 전부 RGBA 투명 배경이다.

| 레이어 | 캔버스 | 계약 |
| --- | --- | --- |
| `tower_back.png` | 256×256 | 사람·분리된 기본 공격 공구가 없는 건물 전체. 특화 고정 소품 포함 |
| `tower_front.png` | 256×256 | 같은 건물 픽셀에서 추출한 전면 작업대/난간, 같은 좌표 |
| `weapon.png` | 1024×512 | 256셀 4열×2행. 정면/오른쪽/후면/왼쪽, 대기/실제 발사 작동 |
| `operator.png` | 1024×256 | 같은 4방향 작업자 1명 |
| `loader.png` | 1024×256 | **코볼트 4종에만** 추가되는 두 번째 작업자 |

6종×4장 + 코볼트 4종×5장 = 44 PNG다. 사람·무기를 건물에 합쳐 굽지 않는다. 방향은 독립 원화이며 단순 좌우 반전을 사용하지 않는다. 작업자는 방향당 한 포즈이며 별도 장전 애니메이션은 없다. 공구는 회전 받침을 포함하고 실제 발사 때만 짧게 작동 행을 사용한다. 몸통과 도구를 따로 늘리지 않으며 모든 레이어를 같은 표시 사각형으로 변환한다. 발 기준점·플랫폼 높이·인원은 각 `meta.json`에 기록한다. 전면 난간은 마지막에, 무기와 사람은 방향별 앞뒤 순서로 그린다.

공통 기본 공격 공구는 작은 기계식 충격 해머다. 인력반은 수동 투석 공구다. 톱·크레인 집게·개틀링 시제품·드릴은 승인된 **특화 실루엣용 고정 소품**이다. 노스킬 판에서 돌아가거나 발사하거나 새 병력을 소환하지 않는다. 실제 유료 스킬 판정·애니메이션의 구현 완료를 이 소품으로 주장하지 않는다.

## 기본 공격·투사체·검수

[투사체 공통 규격](PROJECTILES.md)을 따른다. `engineer_bolt`는 물리 공구탄, `engineer_stone`은 인력반 작업석, `engineer_shock`은 실제 세 번째 강화 공격의 작은 청록 충격 표시다. 비행 256×64(64셀×4), 명중 128×32(32셀×4)이며 모두 4개 서로 다른 프레임을 쓴다. 기본 물리 피해·추적·스턴 판정은 모델이 결정한다. 연출이 추가 피해·새 기절·관통·피해 범위를 만들지 않는다.

공병 노스킬 `engineer-01`은 2열×5행 풀밭·U자 흙길·고블린에서 10종을 함께 보여준다. 실제 짧은 사거리를 유지하기 위해 길만 타워 주변으로 작게 배치한다. 동일한 고체력 적 2명이 네 방향을 지나게 하며 실제 네 방향 발사를 완료 조건으로 삼는다. 사거리를 늘리거나 스킬을 무료로 주지 않는다. 기존 3타 기절은 일반 두 번의 물리 명중과 구분한다. 벽 ON/OFF 비교가 가능하다.

노움 II·코볼트 II는 현행 별도 모델이 없으므로 I와 동일 전투 성능의 디자인 비교다. 라벨 `*`로 표시한다. Art Studio의 투사체 테스트 목록은 승인된 18종과 공병 후보 3종, 총 21종이다. 공병 투사체의 원격 수정본 버튼은 `engineer-v1`을 선택한다. Reload/F6로 같은 크기·기준점의 최신 수정본을 비교한다. 부분 다운로드·규격 오류에는 완전한 내장 시안으로 돌아간다.

원화는 승인된 전체 보드를 참조해 OpenAI 이미지 생성으로 제작하고, 기계적인 알파 잡음 정리·셀 추출·크기/발 좌표 정규화 후 조립한다. 투사체는 [원본 SVG 생성 도구](tools/build_engineer_projectiles.py)로 제작한다. 출처·원본 식별자는 메타데이터에 보존한다.
