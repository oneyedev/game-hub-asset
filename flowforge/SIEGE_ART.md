# 공성 타워 디자인 규격 v1

승인된 10종 콘셉트를 `siege-v1` 스튜디오 후보로 정규화한다. 게임 `siege-01`에서 Art Studio → **Siege v1 (studio)**를 선택한다. 기본 번들 채택은 별도다. 타워 50 PNG와 투사체 8 PNG, 총 58 PNG를 원격 비교한다.

## 형태와 구조

| 디자인 | 모델 역할 | 필수 실루엣 |
| --- | --- | --- |
| 공성 I·II | 기본 I·II | 초라한 목재 발판, 작은 철제 대포 |
| 중병기 I·II | 중병기 | 낮은 콘크리트·모래주머니, 현대식 강철 포신·방패·주퇴기 |
| 벽력포 | 벽력포 | 큰 구경의 현대식 곡사포, 단일 포신 |
| 발리스타 | 발리스타 | 현대 금속 복합궁, 대칭 활대·케이블·중앙 볼트 레일 |
| 서커스 I·II | 서커스 | 적색·크림색 큰 천막이 본체, 지붕 위 포대·대포 |
| 곡예사 | 곡예사 | 청록·크림 천막, 지붕 위 대포, 고정 소품인 링과 공 보관대 |
| 광대 | 광대 | 자주·크림 천막, 지붕 위 대포, 고정 소품인 뿅망치 |

모든 형태에 작업자 **정확히 2명**. 깃발·인장·문장·별 무늬·로고는 금지한다. 중병기는 중세 목제/황동 대포로 표현하지 않는다. 서커스 대포는 천막 내부가 아니라 **천막 위**에 있다. 중병기 II·서커스 II는 현재 별도 모델이 없으므로 I와 동일 성능의 디자인 비교다. 새 능력치·스킬을 부여하지 않는다.

## 레이어·아틀라스 계약

`sets/siege-v1/towers/siege/<form>/` 아래 다섯 레이어를 한 패키지로 다룬다. 모든 PNG는 RGBA 투명 배경이다.

| 파일 | 캔버스 | 역할 |
| --- | --- | --- |
| `tower_back.png` | 256×256 | 무기·사람 없는 완전한 건물·바닥·고정 소품 |
| `tower_front.png` | 256×256 | 같은 건물 픽셀에서 추출한 전면 난간 |
| `weapon.png` | 1024×512 | 256셀 4열×2행: 전/우/후/좌, 대기/실제 발사 반동 |
| `operator.png` | 1024×256 | 전/우/후/좌의 조작수 1명 |
| `loader.png` | 1024×256 | 전/우/후/좌의 장전수 1명 |

방향마다 독립 원화를 사용하며 좌우 반전으로 대체하지 않는다. 건물 하단은 `(128,245)`. 플랫폼 높이와 무기/작업자 발 기준점은 각 `meta.json`에 기록한다. 전면 난간은 원본 건물과 같은 좌표에 놓는다. 사람과 대포가 건물에 구워져 있으면 안 된다. 무기는 회전 받침까지 포함하며 실제 발사 후 짧은 반동 행을 사용한다. 작업자는 방향당 한 포즈이며 장전 전용 애니메이션은 아직 없다.

건물 후면 → 방향별 무기/두 작업자 깊이 순서 → 전면 난간으로 그린다. 후방 조준은 무기 후 사람, 전방은 사람 후 무기, 측면은 먼 사람→무기→가까운 사람 순서다. 천막·포대·작업자는 같은 월드 기준점에서 조립한다.

## 기본 공격과 디자인 테스트

[공통 투사체 규격](PROJECTILES.md)의 4프레임 계약을 사용한다. 공성 철포탄 `siege_shell`, 현대 중병기 포탄 `siege_heavy`, 발리스타 볼트 `siege_bolt`, 서커스 포탄 `siege_circus`를 제공한다. 작은 충돌 연출은 실제 판정과 연결하며 추가 피해를 만들지 않는다.

포탄은 발사 시 정한 **고정 지면**으로 곡선 시각 궤적을 그리며 착탄한다. 표적이 이동하거나 죽어도 표적을 쫓지 않는다. 빗나간 포탄도 실제 지면 폭발은 표시하되 피해는 모델 판정만 따른다. 발리스타는 실제 관통한 적마다 한 번만 충돌 연출을 내며, 원래 표적·거대형 종료 규칙을 따른다. 서커스 노스킬 포탄에 스킬의 튀기기·불의 링·망치 연쇄를 임의로 넣지 않는다.

`투사체 테스트`에서 18종 중 공성 4종을 선택해 방향·배율·느린 재생·프레임·비행/명중을 검사한다. `원격 수정본`은 선택된 투사체에 맞는 세트로 이동한다. 노스킬 판은 2열×5행 U자 흙길·풀밭·고블린이며, 모든 타워가 실제 사거리에서 네 방향으로 공격한다. 벽 ON/OFF로 이웃 도로 표적을 비교한다. 고체력 적은 방향 관찰용이며 최종 게임 밸런스가 아니다.
